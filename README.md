# Week 4 - Functions and Toolbox Assignment

This assignment practices creating and using functions to avoid repeating code.

**Files:**
- `welcome.py` - Contains a single `welcome()` function that returns a personalized greeting, called three times.
- `toolbox.py` - Contains three utility functions: `double()` to double a number, `is_pass()` to check if a score is 50+, and `greet()` with an optional greeting parameter.

The hardest function to write was `greet()` because I had to understand how default parameters work and how to correctly build the final string with comma and exclamation.
